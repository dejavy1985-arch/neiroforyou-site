Для отзыва согласия откройте «Настройки cookies», отключите аналитику и сохраните выбор. Если Метрика уже работала, страница перезагрузится без её запуска. 8. Обработка данных в приложении Mamavdele AI bot (Threads)

Оператор использует собственное приложение «Mamavdele AI bot», подключённое к Threads API компании Meta, для ведения профессионального блога в социальной сети Threads.

Кто пользуется приложением. Приложением пользуется только сам Оператор для собственного аккаунта @mamavdele.ai. Приложение не предоставляется третьим лицам, не является сервисом для других пользователей и не имеет функции регистрации.

Какие данные обрабатываются. Приложение получает через официальный Threads API:

  • публикации Оператора и их статистику;
  • публичные комментарии к публикациям Оператора: текст комментария, имя пользователя автора, дату публикации, ссылку на комментарий;
  • публичные публикации других пользователей, найденные по ключевым словам профессиональной тематики, и их тексты;
  • обезличенную статистику: количество просмотров, отметок «нравится» и ответов.

Приложение не запрашивает и не получает адреса электронной почты, телефоны, данные о местоположении, списки контактов, личные сообщения и любые непубличные данные пользователей Threads.

Цели обработки. Данные используются исключительно для того, чтобы Оператор мог отвечать на комментарии и участвовать в профессиональных обсуждениях по своей теме: искусственный интеллект, автоматизация и ведение малого бизнеса.

Передача третьим лицам. Тексты публичных публикаций и комментариев передаются в сервис Anthropic (Claude) для подготовки черновика ответа. Передаётся только текст публикации и текст комментария. Имена пользователей, идентификаторы и любые иные данные в этот сервис не передаются. Политика Anthropic: anthropic.com/legal/privacy

Иным третьим лицам данные не передаются, не продаются и не используются для рекламы или профилирования.

Хранение. Данные хранятся локально на оборудовании Оператора не дольше 30 дней и используются только для того, чтобы не отвечать дважды на один и тот же комментарий. По истечении срока данные удаляются автоматически. Резервные копии не создаются.

Права пользователей Threads. Любой пользователь Threads вправе потребовать удалить относящиеся к нему данные из хранилища приложения, обратившись по контактам, указанным в настоящей Политике. Требование исполняется в течение трёх рабочих дней. Также пользователь может в любой момент удалить свой комментарий в Threads: после этого он перестаёт обрабатываться приложением.

Автоматизация. Ответы готовятся с использованием языковой модели и публикуются от имени Оператора. Оператор несёт полную ответственность за содержание опубликованных ответов. Приложение не рассылает сообщения, не добавляет подписчиков, не совершает массовых действий и соблюдает ограничения, установленные Meta.
